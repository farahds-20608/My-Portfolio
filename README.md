# My Portfolio

A professional full-stack portfolio for a first-year BCA student.

## Tech stack

- React + Vite
- CSS
- Node.js
- Express.js
- MongoDB + Mongoose

## 1. Run the frontend

Open a terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the URL shown by Vite, usually:

http://localhost:5173

## 2. Run the backend

Open a second terminal:

```bash
cd backend
npm install
npm run dev
```

Backend:

http://localhost:5000

## 3. Connect MongoDB

Create a `.env` file inside `backend` by copying `.env.example`.

Then replace `MONGODB_URI` with your MongoDB connection string.

Restart the backend.

## 4. Customize

Replace these placeholders in `frontend/src/App.jsx`:

- Your Name
- Your College Name
- Your School Name
- yourmail@gmail.com
- GitHub URL
- LinkedIn URL
- Project details
- Certificate details

For your real profile photo, replace the `profile-placeholder` div with an image later.
